# Open AI API

Локальное веб-приложение для общения с Codex через браузер. История чатов
сохраняется на компьютере, а голосовые сообщения распознаются локально.

FFmpeg, Whisper и остальные зависимости собираются внутри Docker-контейнера —
устанавливать их вручную не нужно.

## Требования

- [Docker Desktop](https://www.docker.com/products/docker-desktop/), запущенный
  на компьютере.

## Запуск

1. Склонируйте репозиторий и перейдите в его папку:

   ```bash
   git clone https://github.com/serbium-labs/open-ai-api.git
   cd open-ai-api
   ```

2. Создайте файл с настройками из примера:

   ```bash
   cp .env.example .env
   ```

   В Windows PowerShell используйте:

   ```powershell
   Copy-Item .env.example .env
   ```

   > Без файла `.env` приложение не запустится.

3. Соберите и запустите приложение:

   ```bash
   docker compose up --build
   ```

   Первая сборка может занять некоторое время: Docker автоматически соберёт
   Whisper и подготовит FFmpeg. При следующих запусках достаточно выполнить:

   ```bash
   docker compose up
   ```

4. Откройте в браузере <http://localhost:5173>.

Чтобы остановить приложение, нажмите `Ctrl+C` в терминале.

## Авторизация Codex

Приложение автоматически использует авторизацию Codex из папки `~/.codex` на
вашем компьютере.

Если эта папка находится в другом месте, укажите путь через переменную
`CODEX_AUTH_DIR` перед запуском Docker Compose:

```bash
CODEX_AUTH_DIR=/полный/путь/к/.codex docker compose up
```

В Windows PowerShell:

```powershell
$env:CODEX_AUTH_DIR = "C:\полный\путь\к\.codex"
docker compose up
```

## Использование

- Введите сообщение и нажмите `Enter` или кнопку отправки.
- Для переноса строки используйте `Shift+Enter`.
- Чтобы отправить голосовое сообщение, нажмите кнопку микрофона, запишите речь
  и остановите запись.
